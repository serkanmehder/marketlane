# MarketLane

A research platform for studying AI shopping decisions.

MarketLane provides a controlled online shopping environment for examining how AI agents evaluate products, compare prices, and make decisions on behalf of users.

## Research focus

- How price presentation and additional fees influence product selection.
- Whether agents reconsider their choices as new information becomes available.
- How shopping decisions differ across AI models and task instructions.

## About this repository

This repository provides a public overview of the project. The application code, experiment runners, prompts, and research data are maintained privately.
